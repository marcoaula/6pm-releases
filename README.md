# 6PM

A small Mac answering machine for friends. Leave a voice note any time; it plays at 6 PM.

**Download:** see [Releases](https://github.com/marcoaula/6pm-releases/releases/latest).

- **Mac with an Apple chip (M1 or later):** `6PM-x.y.z-arm64.dmg`
- **Intel Mac:** `6PM-x.y.z.dmg`

6PM is for Mac only.

This early version isn't signed yet: after dragging 6PM to Applications, right-click it and choose **Open** the first time (or System Settings → Privacy & Security → Open Anyway).

This repository only holds the installers. More at [hey6pm.com](https://hey6pm.com).
