# 6PM

A small Mac answering machine for friends. Leave a voice note any time; it plays at 6 PM.

**Download:** see [Releases](https://github.com/marcoaula/6pm-releases/releases/latest).

- **Mac with an Apple chip (M1 or later):** `6PM-arm64.dmg`
- **Intel Mac:** `6PM-x64.dmg`

6PM is for Mac only.

This early version isn't notarised yet. Drag 6PM to Applications and open it. The first time, macOS says it can't verify 6PM: click **Done**, then open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.

This repository only holds the installers. More at [hey6pm.com](https://hey6pm.com).
